# escape probability

픽셀 아트로 표현한 **확률 기반 빌딩 탈출 게임**입니다. 짧은 발판을 따라 옥상에서 지상으로 내려오세요. 여러 층을 한 번에 건너뛰면 빠르지만, 착지 룰렛에서 살아남을 확률이 낮아집니다.

## 플레이

| 건물 | 높이 | 위험 요소 |
|---|---:|---|
| 1단계 | 10층 | 작은 발판과 빈 공간 |
| 2단계 | 20층 | 발판 위 화염 |
| 3단계 | 30층 | 화염, 착지 후 무너지는 발판, 아래쪽을 가리는 연기 |

각 건물의 지상에 도착하면 탈출입니다. 1·2단계 탈출 후 상점에서 아이템을 구입하거나 건너뛴 다음, 다음 건물의 옥상으로 이동합니다. 마지막 30층 건물의 지상을 통과하면 전체 완료입니다.

### 조작

- **Enter**: 시작 / 상점에서 다음 건물로 이동
- **A·D / ←·→**: 좌우 이동
- **Space / ↑**: 점프. 커피가 있으면 공중에서 한 번 더 점프
- **P / Esc**: 일시정지·계속
- **R**: 새 게임
- **1 / 2**: 상점에서 쿠션 / 커피 구매
- 화면 버튼으로 이동·점프·일시정지·구매도 가능합니다.

창이 포커스를 잃거나 최소화되면 자동으로 일시정지됩니다. 창으로 돌아온 뒤 **P / Esc 또는 RESUME**으로 직접 재개합니다.

### 착지 확률과 아이템

한 번에 `n`층을 내려와 새 발판에 착지할 때의 생존 확률:

```text
q(n) = 0.9 ^ (n × (n + 1) / 2)
```

한 층씩 내려가는 것보다 여러 층을 한 번에 떨어지는 편이 위험합니다. 룰렛은 실제 표본과 생존/사망 구간을 표시하며, 작은 확률을 강제로 0%나 100%로 바꾸지 않습니다.

- **LIVE**: 내려온 층당 100코인 획득, 연속 생존(STREAK) 증가
- **쿠션 — 600코인**: 룰렛 사망 한 번을 SAVED로 바꿉니다. 해당 착지 코인은 받지 못합니다. 화염·장외 추락은 막지 못합니다.
- **커피 — 200코인**: 공중 점프 한 번
- **사망**: 현재 건물 옥상에서 재도전. 코인은 그 건물 진입 시 잔액으로 돌아가며, 아이템과 연속 생존은 초기화됩니다.
- 같은 층의 다른 발판에 착지하는 것만으로 코인이나 룰렛을 반복 획득할 수 없습니다.

## 실행 / 빌드

**JDK 17**을 권장합니다. Gradle Wrapper가 포함되어 있습니다. 첫 빌드에는 의존성 다운로드를 위한 인터넷 연결이 필요하며, 별도 계정이나 게임 서버는 필요하지 않습니다.

```sh
# 소스에서 바로 실행
./gradlew lwjgl3:run

# 실행 가능한 JAR 및 Linux/Windows 실행 스크립트용 파일 생성
./gradlew prepareRelease
sh release/run-linux.sh
```

Windows에서는 `gradlew.bat prepareRelease` 후 `release\run-windows.bat`를 사용합니다. Windows/macOS 네이티브 실행은 이번 검증 범위에 포함되지 않았습니다.

### 테스트

테스트 데이터는 실제 플레이어 파일과 분리합니다. 아래 명령은 Linux/macOS 셸 기준입니다.

```sh
TEST_DATA="$(mktemp -d)"
./gradlew --no-daemon -Droulette.dataDir="$TEST_DATA" :core:test prepareRelease
```

`core/src/test`의 규칙·기록 보존·UI 상태 테스트를 실행합니다. 게임 상태를 강제로 설정하는 단위 테스트 fixture는 실제 플레이 영상이나 배포 실행 경로가 아닙니다.

## v14 개선

- 포커스 이탈·최소화 시 자동 정지, 명시적 재개
- 작은 창에서도 읽기 쉬운 HUD·조작·상점 글씨
- 미보유 아이템 표시 제거와 짧은 STREAK 강조
- 상점에서 구매 가능 / 부족 코인 / 이미 보유 상태 표시
- 실제 `%` 비트맵 글리프 추가
- 현재 10·20·30층 게임에 맞춘 문서 정리

게임의 확률·화염·붕괴·아이템 가격·코인 규칙은 변경하지 않았습니다. 기존 버전의 기록 파일은 덮어쓰지 않습니다. 현재 하강 게임은 이전 버전의 기록 저장 기능을 사용하지 않습니다.
