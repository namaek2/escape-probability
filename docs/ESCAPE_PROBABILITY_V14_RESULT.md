# escape probability — v14 검토·개선 결과

## 반영한 개선

- **포커스 안전성:** 창 포커스 이탈·최소화 시 정지. 복귀해도 자동으로 재개되지 않는다. P/Esc/RESUME으로 재개한다.
- **가독성:** HUD·조작 버튼·상점·층 표시의 작은 글자를 확대했다. 미보유 아이템의 NO 표시는 제거했다.
- **연속 생존:** 기존 STREAK 카운터에 짧은 크기 강조와 강조선을 추가했다. 점수 배수나 확률 보정은 추가하지 않았다.
- **상점:** 구매 가능·부족 코인·이미 보유 상태를 버튼에서 구분한다. 쿠션이 화염을 막아준다는 오해가 없도록 설명을 명확히 했다.
- **확률 표기:** 실제 `%` 비트맵 글리프를 추가하고 자산 manifest 해시를 갱신했다.
- **문서:** 구형 게임을 설명하던 README를 현재 10·20·30층 규칙과 실행 방법으로 교체했다.

`GameRules`, `Terrain`, 기록 보존 코드는 변경하지 않았다. 원래의 확률·난수 추첨·물리·아이템 가격·사망 처리·시간 동결을 유지한다.

## 실제 검증

- JDK 17 / Gradle: `:core:test prepareRelease` 성공. **25 tests / 0 failures / 0 errors / 0 skipped**.
- 포커스 회귀 검사는 기존 코드에서 실패한 뒤 수정본에서 통과했다. 상점 상태 검사도 실패→통과를 확인했다.
- 960×600 독립 Xvfb 창에서 실제 키 입력, 포커스 이탈 시 시간·좌표 동결, 복귀 후 정지 유지, 명시적 재개를 확인했다.
- 고정 seed **431**과 실제 OS 키 입력으로 10층 → 상점 → 20층 → 상점 → 30층 건물로 이동했다. 위치·결과·무적을 강제하지 않았다.
- 3단계에서 발판 균열·붕괴, 화염, 연기, 연속 생존 증가를 실제 화면으로 확인했다.
- 3단계 깊이 10에서 발판들을 건너뛰어 깊이 18에 착지했다. **한 번에 8층 낙하**, 생존 확률 `0.022528399544939195`, 표본 `0.9547270344141925`로 룰렛 사망 후 해당 건물 옥상으로 돌아왔다. 화면은 생존 2.25% / 사망 97.75%를 표시했다.
- 배포 후보 ZIP의 CRC와 원본 바이트를 확인하고 새 디렉터리에 추출했다. 소스 프로젝트 밖 cwd에서 포함된 Linux 런처를 실행해 이동·정지·재개까지 확인했다.
